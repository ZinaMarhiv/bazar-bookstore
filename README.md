# Bazar.com — Distributed Bookstore

Distributed Operating Systems lab project built by a two-person team.

## Planned stack

- Node.js, Express, and TypeScript
- SQLite for persistent storage
- Docker Compose for deployment
- HTTP REST APIs with JSON responses

## Services

- frontend-service: public API gateway on port 3000
- catalog-service: book catalog and inventory on port 3001
- order-service: purchase processing and order history on port 3002

## Documentation

The docs directory will contain the design report and demonstration output.
